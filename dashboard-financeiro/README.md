# Dashboard Financeiro

Dashboard financeiro responsivo desenvolvido para demonstrar, na prática, conhecimentos em React.js, JavaScript, componentização, organização de dados e construção de interfaces orientadas a indicadores.

> **Status:** 🚧 Em desenvolvimento — este repositório representa a primeira versão do projeto e será evoluído com API REST, persistência de dados, autenticação e testes.

## 🎯 Objetivo

Criar uma aplicação que permita visualizar e acompanhar receitas, despesas e saldo de forma simples, com indicadores e gráficos para apoiar a análise financeira.

## 🛠️ Stack planejada

- JavaScript

- API REST

- Git / GitHub

## ▶️ Executando o frontend

```bash
cd frontend
npm install
npm run dev
```

Depois, acesse a URL exibida pelo Vite no terminal.

- Uso de `map`, `reduce` e propriedades derivadas
- Organização de um projeto pensando em evolução para uma arquitetura frontend + backend
- Construção de uma interface responsiva
